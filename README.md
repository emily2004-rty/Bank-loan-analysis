## Bank Loan Analysis Dashboard
This project presents an interactive Bank loan Analysis Dashboard that provides comprehensive insights into loan distribution,borrower characteristics,
repayment status and financial ris patterns.The dshboard enables stakeholders to monitor lending performance and make data driven decision.

## Problem Statement
Financial institutions handle thousands of loan applications making it difficult to:
1.Monitor loan performance in real time
2.Identify high risk segments
3.Understand borrower profiles
4.Track repayment trends
5.Optimize lending strategies

Without proper analytics, banks may face:
1.Increased default rates
2.Inefficient capital allocation
3.Poor risk assessment
4.Missed growth opportunities

## Tech stack

This dashboard was bult using the following tools and calculations
Power BI Desktop:Main data visualisation used for report creation
Power query:Data transformation and cleaning for reshaping and preparing the data
File format: .pbix for development and .png for dashboard previews

## Business insights and impact
Loan performance:Majority of loans are fully paid indicating healthy repayment behavior and charged off loans highlight potential credit risks.
Home ownership trends:Most borrowers fall under rent and mortgage.Ownershi status influence loan approval and repayment patterns
Purpose of loans:MOst people take loan because of debt consolidation,home improvement,credit card refinancing and major purchases
Income vs loan amount:Higher groups tend o secure larger loans while lower income segment may reresent higher default risk.
